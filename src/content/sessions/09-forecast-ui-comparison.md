## Before the lab

Pick one forecasting domain — weather, sport, an election, a market — with
at least three widely used interfaces you can access during the lab.

## In the lab

Capture the same forecast from each interface at roughly the same time, so
you're comparing representations of the same underlying prediction rather
than three predictions that happen to differ. Then work through each one
asking a fixed question: if this forecast is wrong, does the interface give
you any way to have expected that in advance?

Group discussion ranks interfaces across different domains against each
other — is a weather app's single rain icon more or less honest than a
poll tracker's single percentage? The answer usually isn't obvious, and
defending a ranking out loud is most of the lab's value.
