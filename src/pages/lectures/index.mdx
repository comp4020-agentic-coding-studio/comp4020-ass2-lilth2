# Lectures

Twelve weeks, twelve distinct predictive-text domains — T9 and multi-tap,
autocorrect, query completion, AAC and assistive input, code completion,
smart replies, conversational chat, image inpainting, forecasting,
co-writing, feed recommendation, and a closing lecture on persuasive design.
Each week is dated, linked to the lab and assessment it feeds, and week 1
carries a full slide deck.
